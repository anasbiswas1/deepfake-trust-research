# Legacy artifacts (pre-correction)

Everything in this directory predates the ECE estimator correction documented in the
repository README and in manuscript v2 (arXiv:2606.29484v2). The drafts, figures, and
derived tables here reflect quantities computed under the legacy stable-sort estimator
and include claims the corrected manuscript revises or withdraws. They are preserved
unchanged for the historical record; current results live in `audits/`,
`reports/calibration/*_tiesafe*`, and `figures/v3_fig_*`. Pre-correction notebooks
reference the original `reports/calibration/` and `figures/` paths for some of these
files; consult this directory when replaying them.
